The N-Queens Problem

Algorithms, Complexity & AI Concepts

♟️
The Problem
Place N non-attacking queens on an N×N board. A queen attacks along rows, columns, and both diagonals. For N=8, there are 92 solutions out of 4 billion+ possible placements.
🌲
Backtracking
A depth-first strategy that builds a solution incrementally and backtracks the moment a constraint is violated. It navigates a decision tree systematically.
✂️
Pruning
Forward checking cuts off dead branches early. If any future row has zero safe columns after a placement, that entire subtree is abandoned immediately.
🧮
Constraint Satisfaction
N-Queens is a classic CSP. Variables = queen positions, Domains = board columns, Constraints = no-attack rules. Backtracking is the standard CSP solver.
🔗
State Space
Naive brute-force faces N^N states. Placing one queen per row reduces it to N!. Forward-checking pruning cuts this by orders of magnitude further.
🎓
Real-World Use
These techniques power VLSI circuit design, parallel memory systems, job scheduling, and constraint logic programming — real AI engineering problems.

Algorithm Pseudocode

solve(board, row): if row == N: return SUCCESS // All N queens placed! for col in 0..N-1: if isSafe(board, row, col): // Constraint check board[row][col] = QUEEN // Place queen if forwardCheck(board, row+1): // Pruning! result = solve(board, row+1) // Recurse deeper if result == SUCCESS: return SUCCESS board[row][col] = EMPTY // Backtrack return FAILURE

Forward Checking (Pruning)

forwardCheck(board, nextRow): for row in nextRow..N-1: safeCols = 0 for col in 0..N-1: if isSafe(board, row, col): safeCols++ if safeCols == 0: return FALSE // Prune this entire subtree! return TRUE

Why It Works So Well

The core insight is constraint propagation: placing a queen eliminates an entire row, column, and two diagonals from future consideration simultaneously.

Forward checking amplifies this — if any future row would be left with zero valid placements, we prune the whole subtree before wasting any work.

For N=8: brute-force visits ~16 million nodes. Backtracking + forward checking visits fewer than 200. That is a 99.999 % reduction in search space.
